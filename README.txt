DOWN UNDER — AUSTRALIA ARRIVAL GUIDE

HOW TO OPEN
1. Keep index.html, style.css and script.js in the same folder.
2. Double-click index.html to open the site in Chrome.
3. You need an internet connection for the photos, fonts and external links.

HOW TO EDIT
- index.html: words, sections and links.
- style.css: colours, layout and design.
- script.js: tips, checklists and tourist-place details.

WHAT IS INCLUDED
- Simple advice for before the flight and the first days.
- Links to useful official sites, shops, transport and job websites.
- A bright tip card that changes colour for emergencies, jobs, money and other topics.
- Click a city name or “See places and photos” to open places to visit, pictures and links.
- Checklists save in this browser on this device.

NOTE
This is a static website. It does not have user accounts or cloud syncing. Rules can change, so check official Australian and state websites for the latest information.

Weather troubleshooting: live conditions need an internet connection. If weather cannot load, the card now shows an error instead of spinning forever; use Refresh weather to try again. Tourist panels and other expandable details show plus/minus state.
